# ADR-0001. Способ развёртывания TimeCapsule

- Статус: принято
- Дата: 2026-10-04

## Контекст

Приложение TimeCapsule работает на сервере AWS EC2. Код приложения хранится в репозитории GitHub.

Нужно выбрать способ, с помощью которого новые версии приложения будут загружаться на сервер.

## Решение

Для этой работы выбран ручной деплой через Git.

Сначала изменения отправляются с компьютера в GitHub с помощью `git push`. Затем выполняется подключение к серверу по SSH и команда `git pull`, чтобы сервер получил новую версию кода.

После обновления кода выполняются необходимые команды для установки библиотек, обновления базы данных и перезагрузки PHP-FPM.

## Рассмотренные альтернативы

### 1. Копирование через `scp`

Можно копировать файлы с компьютера прямо на сервер. Это простой способ, но можно случайно забыть скопировать какой-либо файл. Также сложнее контролировать версии приложения.

### 2. Ручной `git pull`

Сервер получает код из репозитория GitHub. Все изменения сохраняются в истории Git, поэтому легче контролировать версии и делать откат.

Этот способ выбран для данной работы.

### 3. Скрипт `deploy.sh`

Можно создать скрипт, который автоматически выполняет все команды деплоя. Это удобнее и уменьшает количество ручных действий.

Для данной работы этот способ не выбран, так как используется ручной вариант деплоя.

## Последствия

Плюсы:
- код хранится в одном месте — GitHub;
- можно видеть историю изменений;
- можно вернуть предыдущую рабочую версию;
- не нужно вручную копировать каждый файл.

Минусы:
- команды деплоя нужно выполнять вручную;
- можно забыть выполнить одну из команд;
- процесс пока не автоматизирован.
